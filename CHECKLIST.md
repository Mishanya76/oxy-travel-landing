## Обязательно заменить / подключить

1. **Отзывы.** Два текста в блоке «Они уже отдохнули с OXY Travel» даны по вашему брифу как примеры. Замените на реальные отзывы из VK или удалите имена до публикации.
2. **Реквизиты.** В футере помеченное поле `need-fill`: ИП/ООО, ИНН, номер в реестре турагентов. Без него блок доверия неполный.
3. **Форма заявки.** Сейчас форма сохраняет данные только в `localStorage` браузера и показывает экран успеха. Подключите отправку в CRM / VK Forms / email до приёма реальных заявок.
4. **Яндекс.Метрика.** В `index.html` есть закомментированный сниппет — вставьте реальный `YM_COUNTER_ID`.
5. **Цены.** Цены в карточках — из публикаций 2026 года. Перед сезоном обновите их или замените на «уточняйте».
6. **ОАЭ.** В доступных публикациях сообщества не нашлось подходящего фото, поэтому карточка сделана яркой градиентной без фото. Если есть фото из поездки в ОАЭ — положите его в `assets/` и замените `.destination--uae`.
7. **Год основания.** «С 2014 года» выведен из даты первой найденной публикации. Уточните у клиента.

## Как открыть

Просто откройте `index.html` в браузере или запустите локальный сервер:

```powershell
python -m http.server 8000
```

Затем перейдите на `http://localhost:8000`.
